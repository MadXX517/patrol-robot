# 语音播报与指令说明(follow / nav 双模式)

巡逻机器人"小星"的全部**语音播报**(车主动说出来)与**语音指令**(你说话控制车)。
覆盖跟随/巡检(follow)与建图导航(nav)两种模式。

## 快速上手

- 唤醒词:**小星**。说"小星,<指令>"即可,如"小星,开始巡逻"。
- 两个独立开关(网页顶部「语音」面板,两个模式都可见):
  - **语音播报(TTS)**:开后车会主动播报状态(到达、检测到目标等)。
  - **语音触发(ASR)**:开后车会聆听你的指令。
- 两个开关互不依赖,可只开其一。
- 语音为全局功能,与 car_llm 互斥(都抢麦),起语音前确保 car_llm 没在跑。
- 联网依赖:TTS/ASR/LLM 走阿里云,断网时语音失效但网页控制不受影响。

## 工作原理(一句话)

你说话 → ASR 转文字 → LLM 理解意图、输出口语回执 + 结构化动作 →
回执直接播报、动作转成对 dashboard 的 HTTP 调用执行;
车的状态变化 → dashboard 发 `/voice/announce` → 播报出来。

# 一、语音指令(你说话 → 车执行)

LLM 把口语映射到下表 function,再由执行器调用 dashboard API。
一句话含多个意图会按顺序执行(如"先巡逻再跟着我")。
无法对应任何功能时,LLM 只当闲聊回应,不会误触发。

## 通用 / 跟随巡检类(两个模式都可用)

| 你说 | 动作 |
|------|------|
| 开始巡逻 / 去巡逻 / 开始工作 | 进入识别记录(视觉巡逻) |
| 跟着我 / 跟上来 / 跟着走 | 人体跟随(底盘跟人,带避障) |
| 看着我 / 盯住我 / 转头跟着我看 | 云台追踪(底盘不动,只转摄像头) |
| 快一点 / 走快点 / 跟快点 | 跟随加速 |
| 慢一点 / 走慢点 / 跟慢点 | 跟随减速 |
| 正常速度 / 速度正常 | 跟随恢复正常速度 |
| 重新锁定 / 锁定我 / 目标丢了重新锁 | 重新锁定跟随目标 |
| 停下 / 别动了 / 都停了 / 停止所有 | 全部停止 |
| 打开手势控制 / 启用手势 | 开手势控制 |
| 关闭手势控制 / 关掉手势 | 关手势控制 |
| 打开雷达 / 开避障 | 开雷达 |
| 关闭雷达 / 关掉雷达 | 关雷达 |
| 生成报告 / 拍照记录 / 记录一下 | 生成巡逻报告 |
| 摄像头往左/右/上/下看 | 云台转向 |
| 摄像头回正 / 云台复位 | 云台复位 |
| 底盘复位 / 底盘回正 / 回正 | 底盘回正 |
| (闲聊 / 自我介绍 / 提问) | 只对话,不动作 |

## 导航类(nav 模式 / 阶段6 新增)

| 你说 | 动作 |
|------|------|
| 进入导航模式 / 切到导航 / 开始导航 | 切换到建图导航模式 |
| **去客厅 / 到厨房 / 前往门口** | 导航到预先命名好的地点 |
| 回到起点 / 回原点 / 回出发点 | 返回起点 |
| 取消导航 / 别去了 / 不去了 | 取消当前导航 |

> 说明:
> - "去/到/前往 + 地点名"统一走 goto_point,地点名取你事先在地图上命名的点(原样中文)。
> - 命名点需先在网页"自主导航"面板里把车开到某处、命名保存(每张地图独立一组)。
> - 导航需先进入导航模式并加载好地图;可一句话"进入导航模式,去客厅"分两步执行。
> - 去一个不存在的点(如"去书房"但没存过),车会播报"没有名为书房的点"。

# 二、语音播报(车主动说出来)

开启「语音播报」后,以下状态变化时车会出声。分两类:
- **对话回执**:你下指令后 LLM 生成的自然应答(如"好的,开始巡逻"),随指令即时播报。
- **状态播报**:车的状态真正变化时由 dashboard 触发(下表)。

## 通用 / 跟随巡检类

| 触发场景 | 播报内容 |
|----------|----------|
| 开机 / 节点就绪 | 系统就绪,我是巡逻机器人小星 |
| 开始视觉巡逻 | 巡逻已开启 |
| 全部停止 | 已全部停止 |
| 跟随停止 | 已停止 |
| 切到云台追踪 | 切换到云台追踪 |
| 锁定目标(跟随) | 已锁定目标,开始跟随你 |
| 锁定目标(追踪) | 已锁定目标 |
| 目标丢失 | 目标丢失,正在重新锁定 |
| 手势唤醒 | 手势已唤醒 |
| 收到手势指令 | 收到手势指令,开始跟随 |
| YOLO 检测到目标 | 检测到<目标>(同类 8 秒内只播一次) |
| 电量低于阈值 | 电量不足,请及时充电 |
| 报告生成完成 | 巡逻报告已生成 / 报告生成失败 |

## 备注

- 同类播报有去抖(如 YOLO 检测 8 秒、巡检状态 2 秒),避免刷屏。
- 播报与对话回执共用同一播放队列,串行播放,不会抢扬声器。
- 指令映射定义见 `car_llm/config/chat_prompt_patrol.yaml`(function 枚举)
  与 `car_voice/car_voice/web_control.py`(function→dashboard API 路由)。
- 播报触发点在 `car_web/car_web/dashboard_server.py` 的各 `self.announce(...)`。
- 设计与阶段拆解见 `car_voice/PLAN_voice.md`。
